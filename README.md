# Coding Ninjas DSA with Java

A personal collection of Java practice programs created while learning the Coding Ninjas Full Stack Development Bootcamp DSA curriculum.

This repository currently contains **89 standalone Java exercises** and supporting notes. It focuses on Java fundamentals, problem-solving, arrays, strings, methods, loops, and pattern printing.

## Topics covered

- Java program structure and introductory programs
- Variables, literals, and primitive data types
- Type casting and operators
- Conditional statements, ternary operators, and `switch`
- `for`, `while`, nested, and `do-while` loops
- Prime numbers, Fibonacci series, digit reversal, random-number guessing, and summation
- Methods, arguments, return values, call stacks, pass-by-value, overloading, and combinations
- One-dimensional arrays:
  - declaration, default values, traversal, memory references, and methods
  - sum, maximum, second-largest element, updates, and insertion
  - reverse, rotation, shifting negative values, shifting zero values, and array sums
- Two-dimensional arrays:
  - creation, traversal, runtime input, methods, and enhanced `for` loops
  - jagged arrays, largest column sum, and spiral traversal
- Strings:
  - creation, memory behavior, input, methods, character arrays, and word counting
  - reversing a string and reversing words using multiple approaches
- Star, number, character, triangle, pyramid, mirror, isosceles, and hourglass patterns
- Notes for pattern-solving and 2D-array spiral traversal
