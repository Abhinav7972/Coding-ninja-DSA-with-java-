# CN_DSA - Java + DSA Learning Journey

This repository is a hands-on collection of Java programs, exercises, and notes built while learning Data Structures and Algorithms in Java.

It tracks a steady progression from core Java fundamentals to object-oriented programming and beginner/intermediate data structures and algorithmic problem solving.

The repository currently covers the following areas:

- variables, literals, and primitive data types
- operators, type conversion, and precedence
- control flow and conditional logic
- loops, nested loops, and number-based pattern programs
- methods, method overloading, and parameter passing
- arrays and 2D arrays
- strings and basic string manipulation
- pattern printing and traversal practice

### Object-oriented programming and Java basics
- classes and objects
- encapsulation and reusability
- inheritance
- polymorphism
- abstraction
- interfaces
- generics
- exception handling
- custom model classes and mini-projects such as `Student`, `Employee`, `Fraction`, `Complex`, and `Polynomial`

### Data structures and algorithm foundations
- linked list implementations
- stacks and stack problems
- queues
- recursion and recursive problem solving
- linear and binary search
- bubble, insertion, selection, and merge sort
- time and space complexity analysis

### Advanced learning covered in this repo
- queue implementations using arrays and linked lists
- generic tree / n-ary tree structure
- tree traversal and node-count logic in Java

### Practice and notes
- array-based exercises and manipulations
- custom class exercises and mini-use cases
- pattern and spiral traversal notes
- Java practice examples for coding interview-style logic

## How to run Java programs

These are practice files, so each program is generally compiled and executed separately.

```bash
javac FileName.java
java FileName
```

If a program depends on another class, compile both together:

```bash
javac Main.java Helper.java
java Main
```

Most files are console-based and may ask for user input.
